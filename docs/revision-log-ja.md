## 初稿チェックリスト（ここまでの修正から抽出）

### 依頼者の好み（最初から反映する）
- [ ] **テンポ**：解説動画は 15 秒だと速い。30 秒前後（各場面に 5〜7 秒）を基本にする
- [ ] **細かい表記を入れない**：「STORAGE · NO.01」「01」「02」などの番号、英字の小見出し（SYSTEM DATA、CONCLUSION、英語のサブコピー）は入れない。日本語の小見出しと ※注記は残す
- [ ] **縦型はセーフマージン内**：1080×1920 では、紹介中に映る要素をすべて内側の枠（x 64〜1016、y 112〜1808 ＝ 左右 約60px・上下 約110px）に収める。カメラの寄り（ズーム）分も含めて確認する
- [ ] **縦型は作り直す**：横型を縮めたり切り抜いたりせず、縦に積むレイアウトと大きい文字で組み直す
- [ ] **日本語は Noto Sans JP**。自然な日本語・正しい約物で書く
- [ ] **紹介の順番は依頼内容どおり**（例：店舗マップは東京→大阪→福岡→鹿児島。地図の組み上がりも最初に紹介する地点から始める）
- [ ] 実在のロゴがない場合は仮ロゴにして、その旨を伝える

### 書き出す前に静止画で確認すること
- [ ] **画面端の切れ**：ステッカーや画像が画面外にはみ出していないか
- [ ] **同じ情報の重複**：同じ数字（例：約410GB）を 2 か所に出していないか
- [ ] **要素同士の重なり**：スタンプ・ラベル・タイトルが他の要素やラベルに重なっていないか
- [ ] **文字の折り返し・欠け**：狭い場所の文字（例：「空き 50GB」）が 2 行に折れていないか、カードの文字が枠で切れていないか
- [ ] **カメラ移動中の空白**：場面転換の途中で何も映らないフレームがないか（次の場面の見出しを移動開始と同時に出す）
- [ ] **構図の偏り**：画面の半分が空いていないか（地図などは見る角度を変えて画面を埋める）
- [ ] **フォント**：使うフォントがすべて揃っているか（足りないと書き出しが止まる）
- [ ] **数値の整合性**：グラフの長さと数字が同じ計算から出ているか

## 技術的なメモ
- 書き出しは `.\render-win.ps1 demos\<フォルダ名>`。静止画だけなら `--stills '1,5,9'`（カンマ区切りは引用符で囲む）
- 縦型 SSD（28）は `node harness/render.mjs demos/28-ssd-ja-vertical --stills '4.1,10.5' --query 'safe=1'` でセーフ枠を重ねて確認できる
- 店舗マップは `--query 'az=15'` で見る角度、`cam=経度,緯度,ズーム` でカメラ位置を試せる
- 地図データは Natural Earth 1:10m（パブリックドメイン）を world-atlas@2.0.2 経由で取得し、`tools/extract-jp.mjs` で日本だけ抜き出した
